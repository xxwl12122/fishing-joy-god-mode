## 🚀 快速启动

1. **直接运行桌面 EXE 程序（推荐）**：
   - 方式一：直接双击根目录下的 [启动游戏(EXE版).bat](file:///E:/fish-hunter-game/启动游戏(EXE版).bat)。
   - 方式二：进入 [dist\FishingJoy-win32-x64](file:///E:/fish-hunter-game/dist/FishingJoy-win32-x64)，直接双击运行 **`FishingJoy.exe`**。
   - 程序启动后将以**沉浸式全屏**形式直接展现游戏，支持按 `F11` 切换全屏，按 `ESC` 退出全屏。

2. **浏览器直接游玩**：
   - 双击根目录下的 `start_game.bat` 或直接用任意现代浏览器打开 `index.html`。

3. **重新打包 EXE（开发维护）**：
   - 若您后续对代码做出了修改，只需在命令行执行以下命令即可一键重新打包生成 EXE：
     ```bash
     npm run package
     ```
